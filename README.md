# UAV-Collision-Avoidance-Using-Average-Sub-Gradient-Method
Code and Data Availability

The ODE simulation model, the complete simulation model of the ASG (Average Sub-Gradient) method, and the experimental data supporting the findings of this paper are available in the supplementary materials. The repository includes:

MATLAB/Simulink controllers (.slx files)

ROS/Gazebo implementation files

To run the ROS/Gazebo implementation, the PX4 libraries must be installed first. Our controller was adapted to work seamlessly with the PX4 firmware.
